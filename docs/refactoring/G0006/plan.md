# G0006 当下计划：内部创作图、缓存与非破坏性效果底座

> 文档状态：已实施；本地自动化门禁完成，真实 Host 与人工视觉验收待完成  
> 前置阶段：G0005.1 已完成四种生成器入口；作品格式由 v5 升级为 v6

## 目标

在增加实际艺术效果和多图层之前，把现有四条渲染路径统一为插件私有、可保存且可验证的有向无环创作图，
并让预览、九宫格和导出通过同一节点缓存完成局部重算。

## 产品范围

- 规范链路固定为 `生成 → 着色/描边 → 空效果链 → 单层合成 → 输出`；
- Julia/Mandelbrot 生成 `ScalarField`，递归树/L-System 生成 `PathGeometry`；
- 增加只读 `ImageSurface` 和 `Mask`，缓存不持有可被外部修改的数组；
- 保存节点、端口、连接、图版本和空效果链，v1–v5 自动迁移；
- 不向普通用户显示节点图，不增加实际效果、Tool、命令、菜单或快捷键。

## 工作项

1. 定义显式节点操作、端口数据类型、规范图工厂、诊断和稳定拓扑排序；
2. 拒绝重复节点、缺失端点、重复输入、类型不兼容、未连接节点、循环及未知版本；
3. 用窄节点执行器替换生成器专用整链渲染器，保留现有数学、渐变和描边服务；
4. 建立每个 Document Scope 独占的 128 MiB / 256 项 LRU 节点缓存；
5. 缓存键覆盖节点/图/渲染器版本、上游输入、实际参数、尺寸、质量、精度和相关 Seed；
6. 只在节点成功且未取消后写入缓存，错误和半成品不得污染后续运行；
7. 让九宫格使用统一执行摘要判断缓存命中，删除第二份缩略图缓存；
8. 将作品格式升级到 v6，并补齐 v1–v5 迁移、损坏数据和完整往返测试；
9. 固定四类代表作品的 RGBA 指纹，确保图拆分不改变既有视觉结果；
10. 更新产品基线、质量门禁、快速开始与 G0006 专用档案。

## 完成标准

- 相同作品第二次渲染命中全部可缓存计算节点；
- 修改渐变不重新计算标量场或路径，修改线宽不重新生成路径；
- 路径几何可跨预览/导出尺寸复用，像素节点按尺寸与质量正确失效；
- 两个 Document 的缓存实例和生命周期完全隔离；
- 非法图在任何昂贵计算前给出包含节点上下文的中文诊断；
- v1–v5 作品迁移为匹配生成器的规范图和空效果链，视觉指纹保持不变；
- Debug/Release 构建、测试、格式和 Standalone 启动烟雾通过。

## 明确排除

- 不实现 Blur、Glow、Bloom、Grain 或效果参数 UI；
- 不实现节点编辑器、反馈环、多图层或遮罩节点；
- 不使用 AIFLOW，不增加 Windows CI，不执行部署、正式 ZIP、签名或发布门禁。
