# G0003 高精度性能与领域模块化专项结果

> 状态：P01–P07 代码、文档、本地自动化与 Standalone 启动烟雾完成；真实 Host 和人工视觉检查待确认
> 实施日期：2026-09-03

## 完成项

- Domain 已按 Artwork、Viewport、Rendering、Fractals/Julia 模块化，Numerics 成为只依赖 BCL 的支撑模块；
- 配置精度、所需精度和有效精度已分离，配置不足明确失败，状态栏显示有效/配置位数；
- 定点热路径改为坐标增量、预计算常量、raw `BigInteger` 运算和有界取消检查；
- 默认最多保留一个逻辑核心且不超过 8 路，连续行块独占输出区间；
- 暂态 Bitmap 变换和低成本/精细真实预览形成两阶段交互，旧 generation 仍无法提交；
- 扰动算法具有扩展指数、阈值/非有限 glitch 检测和逐像素权威回退；仅草稿自动使用；
- 作品格式保持 v2，运行时精度、并行度、内核和暂态状态均未进入 JSON。

## 自动化证据

- 原有 30 项测试在重构前通过；专项后共 48 项测试通过；
- 串行、2/4 路与非整除块高精度结果逐值一致，重复运行完全确定；
- 动态精度与配置全精度逃逸掩码一致，标量误差不超过 `0.0001f`；
- 阈值附近样本确实触发配置精度回退并产生诊断；
- 扰动与权威内核逐像素分类一致，极深尺度扩展指数对照通过；
- 连续运行中的高迭代任务可以取消；Document 的取消、关闭与迟到提交测试继续通过；
- v1 → v2、v2 往返、未知版本、恶意指数、PNG 与原子写入测试继续通过；
- 四组 Release 基准指纹与旧实现一致；96/256/1024 位耗时和分配指标均超过计划门槛。
- Standalone 进程响应正常，主窗口句柄非零，标题为 `Fractal Art · Standalone Preview`。
