# G0005.1 当下计划：双生成器入口与可编辑 L-System

> 文档状态：已实施；本地自动化门禁完成，人工视觉与真实 Host 验收待完成
> 前置阶段：G0005 递归路径已经完成；作品格式已从 v4 升级为 v5

## 目标

把当前按控件堆叠的单一右侧属性区改造成“先选择生成器家族，再编辑当前生成器”的创作界面，并正式提供：

1. **逃逸时间**：首批支持 Julia 与 Mandelbrot；
2. **L-System**：首批支持经典示例和可验证的自定义规则；
3. 两个家族都遵守“示例起步、真实参数可继续编辑”的原则；
4. 继续复用 G0005 已有的 `ScalarField`、`PathGeometry`、描边、变体、保存、预览和 PNG 导出能力；
5. 保持 v1–v4 作品可恢复，不以界面简化为理由改变旧作品视觉结果。

## 用户问题

当前右侧区域同时放置画布、预设、变体、Julia、高精度、递归树和颜色。用户需要在很长的滚动区域中判断
“这个参数属于哪一种生成器”，新增 Mandelbrot 和 L-System 后还会继续恶化。

G0005.1 要把对应关系变为显式结构：

```text
生成器家族 → 具体生成器/示例 → 当前生成器专属调控 → 共用外观与探索
```

## 产品范围

### 逃逸时间

首批公式：

- Julia；
- Mandelbrot。

每个公式至少提供 3 个可编辑示例。选择示例只把参数写入当前真实配方，之后修改任意参数即成为“自定义”，
不会保存一份示例状态和一份渲染状态。

### L-System

首批经典示例：

- 科赫雪花；
- 龙形曲线；
- 谢尔宾斯基三角；
- 分形植物；
- 希尔伯特曲线。

自定义区域支持公理、产生式表、迭代层级、转向角、初始方向、步长、长度衰减、线宽及线宽衰减。
首版采用确定性上下文无关规则，不加入概率产生式；不具有随机语义时，界面不显示无效的 Seed 调控。

## 工作项

1. 将左侧导航改为“逃逸时间 / L-System”两个一级选项，并在其下选择具体公式或示例；
2. 将右侧改为当前生成器的上下文检查器，不同时显示不相关参数；
3. 为逃逸时间提供“示例、创作、数学、外观、探索”页签；
4. 为 L-System 提供“示例、规则、绘制、外观、探索”页签；
5. 实现 Mandelbrot 的普通双精度和受预算任意精度路径；
6. 实现 L-System 规则验证、受预算展开、Turtle 解释与 `PathGeometry` 输出；
7. 让示例目录、用户自定义、撤销、Dirty、保存和恢复使用同一份真实定义；
8. 变体保持当前公式/规则，只修改该家族有真实意义的数值参数和颜色；
9. 作品格式升级到 v5，并显式迁移 v1–v4；
10. 保留 v4 参数化递归树的精确兼容，不进行会改变视觉结果的静默近似转换；
11. 补齐领域、应用、Document、持久化、取消、预算、迁移和界面绑定测试；
12. 同步快速开始、产品基线、质量门禁和 G0005.1 实施档案。

## 完成标准

- 用户可以在一级导航中明确选择“逃逸时间”或“L-System”；
- 选择 Julia/Mandelbrot 后只出现逃逸时间相关调控；
- 选择 L-System 后只出现规则、Turtle 绘制及路径外观调控；
- 每个内置示例应用后可以继续编辑，编辑结果保存、关闭、恢复后完全一致；
- Mandelbrot 与 Julia 均输出 `ScalarField`，共用渐变、预览、变体和 PNG 导出；
- L-System 在描边前仍是 `PathGeometry`，规则展开不创建 Bitmap；
- 非法规则、未知符号、栈不平衡、符号预算和线段预算都有明确中文诊断；
- 内置 L-System 示例的展开序列、线段数和输出指纹固定可测试；
- 变体不会随机切换 Julia/Mandelbrot，也不会随机篡改 L-System 规则文本；
- v1–v3 迁移为逃逸时间 Julia；v4 Julia 同样迁移；v4 递归树保持原视觉语义；
- 仍然只有一个 Persistable Document，不新增 Tool、Workbench Command、菜单或默认快捷键；
- Debug/Release 构建、测试、格式与 Standalone 启动烟雾通过。

## 首要工程约束

1. SOLID 是第一评审顺位；公式计算、规则展开、Turtle 解释、描边和 Document 编排必须分离；
2. 设计模式朴素使用，只采用显式类型选择、窄策略、不可变定义和端口/适配器；
3. 不引入反射公式扫描、通用节点图、事件总线、自制 DI 或为两个家族设计的“大一统 DSL”；
4. 领域规则不依赖 Avalonia，UI 示例目录不成为渲染事实来源；
5. 公共边界、规则语义、预算、取消、迁移和过期结果使用详细中文注释；
6. 不使用 AIFLOW，不新增 Windows CI，不执行部署、发布或正式 ZIP 门禁。

## 明确不做

- 不在 G0005.1 实现 Burning Ship、Newton、Fractal Flame 或点云生成器；
- 不实现概率 L-System、参数化 L-System 表达式、上下文相关语法或用户脚本；
- 不建立全局用户预设库；自定义内容随作品保存即可；
- 不实现 SVG 文件写出，但继续保留可供未来 SVG 导出消费的路径语义；
- 不提前实施 G0006 的内部节点图和通用缓存拓扑；
- 不以新的 L-System 近似覆盖旧递归树作品。
