# G0005.1 交互设计：生成器导航与上下文调控

> 文档状态：待实现交互基线

## 总体布局

保留当前单 Document 工作区和底部九宫格，但重新划分左、右区域的职责：

```text
┌────────────────────────────────────────────────────────────────────┐
│ 分形作品  撤销/重做  生成变体  预览质量  重新预览  导出 PNG       │
├───────────────┬──────────────────────────┬─────────────────────────┤
│ 生成器        │                          │ 当前：L-System          │
│               │                          │                         │
│ ● 逃逸时间    │                          │ 示例 规则 绘制 外观 探索│
│   ├ Julia     │        作品画布          │ ─────────────────────── │
│   └ Mandelbrot│                          │ 公理  X                  │
│               │                          │ 规则  X → F+[[X]-X]...  │
│ ● L-System    │                          │ 迭代  5   角度 25°      │
│   ├ 经典示例  │                          │                         │
│   └ 自定义    │                          │ 预算：12,380 / 250,000  │
├───────────────┴──────────────────────────┴─────────────────────────┤
│ 本轮候选：采用 / 收藏 / 续变                                      │
└────────────────────────────────────────────────────────────────────┘
```

左侧回答“正在编辑什么”，右侧回答“当前对象可以怎么调”。画布、底部候选和顶部作品命令保持稳定，用户切换
生成器时不需要重新学习整个工作区。

## 左侧生成器导航

一级固定为两个家族：

```text
逃逸时间
L-System
```

选择逃逸时间后展开公式：

```text
逃逸时间
├─ Julia
└─ Mandelbrot
```

选择 L-System 后展示“示例”和“自定义”入口。经典示例属于可编辑起点，不是只读展示页面。

当前 v4 参数化递归树在迁移后显示在 L-System 家族下的“参数化分形树（兼容）”。它使用原有生成器保证旧作品
逐像素语义不变；新建作品默认不再把它与真正的 L-System 混称。用户可以主动从它创建一个“分形植物”
L-System，但界面必须说明转换不会保证视觉完全一致。

## 右侧上下文检查器

### 逃逸时间页签

| 页签 | 内容 |
| --- | --- |
| 示例 | 当前公式的内置示例；应用、恢复示例 |
| 创作 | 细节、流动、卷曲等面向视觉结果的参数；Mandelbrot 只显示对其有效的映射 |
| 数学 | 中心、尺度、最大迭代；Julia 额外显示复常量 |
| 外观 | 渐变起止色、内部颜色、背景 |
| 探索 | 强度、只变形态/质感、构图/形态/颜色锁定、生成候选 |

### L-System 页签

| 页签 | 内容 |
| --- | --- |
| 示例 | 科赫雪花、龙形曲线、谢尔宾斯基箭头、分形植物、希尔伯特曲线 |
| 规则 | 公理、产生式表、迭代层级、实时规则诊断与预算 |
| 绘制 | 转向角、初始方向、步长、长度衰减、线宽、线宽衰减 |
| 外观 | 层级渐变、背景，后续可扩展端帽与连接样式 |
| 探索 | 强度、形态/质感、形态/颜色锁定；不显示无语义的 Seed 锁 |

页签只影响界面呈现，不改变渲染配方。当前页签可以进入 `ArtworkPresentationDefinition` 保存，撤销作品参数时
不应连带跳页。

## 示例与自定义关系

示例目录只提供真实参数，不保存第二份渲染状态：

```text
选择示例
→ 将示例定义应用到当前作品
→ 当前画面与所有字段立即对应
→ 用户修改任意字段
→ 标题显示“自定义（源自：分形植物）”
→ 保存的是修改后的完整定义
```

“恢复示例”会产生一次普通可撤销修改。若当前有未保存的自定义参数，按钮应说明它会替换当前生成器定义，
但不需要额外弹出模态确认，因为撤销能够恢复。

## 逃逸时间示例目录

第一批示例建议如下，正式实施时用固定输出指纹验证参数：

| 公式 | 示例 ID | 显示名 | 设计目的 |
| --- | --- | --- | --- |
| Julia | `julia-classic` | 经典花环 | 展示连通花环与内部区域 |
| Julia | `julia-rabbit` | 兔形旋涡 | 展示不对称旋涡结构 |
| Julia | `julia-dendrite` | 枝晶 | 展示树枝状细节 |
| Mandelbrot | `mandelbrot-overview` | 曼德博全景 | 展示完整集合和主心形 |
| Mandelbrot | `mandelbrot-seahorse` | 海马谷 | 展示深缩放与重复结构 |
| Mandelbrot | `mandelbrot-elephant` | 象谷 | 展示局部旋臂和卫星结构 |

示例卡显示缩略图、公式名称和一句视觉说明。选择后仍可编辑全部数学参数；Julia 与 Mandelbrot 切换属于一次
可撤销的生成器替换。

## L-System 示例目录

首批规则固定如下；`F/G` 前进并绘制，`f` 只移动，`+/-` 转向，`[` 保存 Turtle 状态，`]` 恢复状态，
`X/Y/A/B` 默认只参与改写而不绘制。

| 示例 | 公理 | 产生式 | 角度 |
| --- | --- | --- | ---: |
| 科赫雪花 | `F--F--F` | `F → F+F--F+F` | 60° |
| 龙形曲线 | `FX` | `X → X+YF+`；`Y → -FX-Y` | 90° |
| 谢尔宾斯基箭头 | `F-G-G` | `F → F-G+F+G-F`；`G → GG` | 120° |
| 分形植物 | `X` | `X → F+[[X]-X]-F[-FX]+X`；`F → FF` | 25° |
| 希尔伯特曲线 | `A` | `A → +BF-AFA-FB+`；`B → -AF+BFB+FA-` | 90° |

每个示例还要声明迭代默认值、初始方向、步长、线宽和适合的渐变，避免规则正确但首次画面位于画布之外。

## 规则编辑器

产生式使用表格而不是要求用户一次输入完整 DSL：

| 符号 | 替换内容 | 操作 |
| --- | --- | --- |
| `X` | `F+[[X]-X]-F[-FX]+X` | 删除 |
| `F` | `FF` | 删除 |

支持增加规则、删除规则和恢复示例。输入时在表格下方持续显示：

- 当前展开符号数 / 最大符号预算；
- 当前绘制线段数 / 最大线段预算；
- 规则是否完整；
- 第一个错误的位置和中文原因；
- 超预算时建议降低到的最高安全迭代层级。

错误存在时保留上一张成功预览，不提交失败配方，不显示“渲染成功”。

## 第一版规则边界

- 公理长度：1–1,024；
- 规则数量：1–32；
- 单条替换长度：0–4,096；
- 迭代层级：0–12，同时受展开预算限制；
- 展开符号总数：不超过 250,000；
- 实际绘制线段：不超过 50,000；
- Turtle 栈深度：不超过 1,024；
- 只接受明确列出的 ASCII 符号，不执行脚本、表达式或宿主代码。

这些边界由领域验证器执行，控件的最大值只是输入辅助，不能作为安全边界。

## 自适应与可访问性

- 右侧建议宽度 360–420，页签内容独立滚动；
- 窗口变窄时左侧可折叠为家族按钮，右侧可切成覆盖式检查器；
- 当前家族、公式和页签必须有文字，不只依赖颜色高亮；
- 规则错误同时显示文本、字段状态和焦点定位；
- 示例卡和页签保持键盘可达，不新增全局快捷键；
- 九宫格仍位于底部，避免把变体参数与候选结果分隔到两个远距离区域。
