# G0008：多图层、遮罩与跨分形组合计划

## 产品结论

将 v6 单生成器直通图升级为 v7 非破坏性合成画布。作品文件只保存画布、顶层图层树、Master Effects
与呈现状态；执行图由图层树确定性构造，不再同时持久化两份可能漂移的关系。

首版限制为 8 个分形层、4 个单层分组，不支持嵌套组。图层和 UI 都按“最上层在前”保存与展示，
执行时从列表底部向上合成，背景只在根级加入一次。

## 实施范围

- Julia、Mandelbrot、递归树和 L-System 均可成为独立分形层；
- 图层和组均支持显隐、名称、不透明度、五种混合模式、位置、统一缩放、旋转、锚点与遮罩；
- 遮罩只读取 Julia/Mandelbrot 原始 `ScalarField`，使用遮罩源自身变换映射到画布空间；
- Master Effects 固定按 Tone → Bloom 执行，并进入保存、Dirty、历史、预览和普通 PNG；
- 九宫格、收藏、锁定、轮次、艺术参数和画布视口均路由到当前选中分形层；
- v1–v6 显式迁移为一个身份变换、Normal、100% 不透明、无遮罩的顶层分形层；
- 未知图层/效果以不可用占位原样保存，但统一阻止预览和所有导出；
- 保持 Plugin/Document ID、Workflow Recipe 外层 v1、Action 和 File Artifact v1 不变。

## 质量与非目标

SOLID 是首要约束：Document 只做命令、选择、异步提交和 UI 投影；不可变树编辑、结构验证、可渲染性、
标量遮罩、栅格变换、混合和 Master Effects 各自使用窄接口。只使用不可变值、简单服务和构造器注入，
不引入事件总线、仓储、反射注册或自制 DI。

本阶段不使用 AIFLOW，不创建或修改 `.aiflow`，不增加 Windows CI，不执行 Release 构建、部署、正式 ZIP、
签名、发布或其他发布门禁。真实 Host 与人工视觉验收单独记录，不能用本地自动化替代。
