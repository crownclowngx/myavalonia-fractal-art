# G0009：第三类数据形态——点云与密度计划

## 产品结论

在现有逃逸时间标量场与递归路径之外，增加“奇异吸引子”生成器家族，首批支持 Clifford 与 De Jong。
两种公式共用 `PointCloud → Density → Gradient → Local Glow` 纵向管线，并作为普通分形层参与变体、缓存、
图层变换、混合、遮罩、保存和导出。

## 首要约束

- SOLID 是实现评审第一顺位；公式、采样、密度、着色、发光和 Document 投影各自承担单一职责；
- 只朴素使用不可变值对象、窄端口、公式策略、构造器注入和 cache-aside；
- 不引入通用节点编辑器、事件总线、仓储抽象、反射注册或自制 DI；
- 公式、确定性分块、整数密度、缓存失效、取消与迁移边界使用详细中文注释；
- 不使用 AIFLOW，不增加 Windows CI，不执行 Release、部署、ZIP、签名或发布门禁。

## 完成标准

- Clifford/De Jong 在 1/2/4/8 路调度下逐点和逐像素一致；
- 普通预览最多 100,000 点，精细预览最多 400,000 点，最终输出最多 2,000,000 点/层；
- 密度可着色、可局部发光、可作为其它层或组的画布空间遮罩；
- v8 完整往返，v1–v7 显式迁移且四类旧生成器输出不变；
- 取消、异常与半成品不进入节点缓存；
- 当前本地 Debug 门禁、格式门禁与 Standalone 烟雾验证通过。
