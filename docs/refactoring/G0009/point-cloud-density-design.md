# G0009 点云、密度与局部发光设计

## 数据链路与职责

```text
Clifford / De Jong 策略
→ 固定逻辑轨道采样器
→ 不可变 PointCloud
→ 整数密度累积
→ 归一化 ScalarField
→ 透明密度渐变
→ 当前层局部发光
→ G0008 图层合成
```

公式策略只执行一次 `(x, y) → (x', y')`；采样器统一负责 Seed、32 条固定逻辑轨道、预热、预算、并发、
取消和数组所有权。实际线程只调度既定数组切片，不改变逻辑轨道或点序，因此并发度不会进入数学结果。

## 点云与密度

`PointCloud` 保存只读 `float` 坐标、边界和缓存体积，不保存像素尺寸。每条逻辑轨道的初值由作品 Seed、
公式和轨道序号经固定 SplitMix64 派生；每轨道独立预热，再写入预先确定的连续切片。

密度阶段按点云边界等比居中并保留 5% 边距。退化坐标轴使用居中单位跨度。每个点用四个总和为 256 的
8 位定点双线性权重落入共享 `int` 直方图，使用整数原子加法；加法结合律保证不同调度顺序产生相同结果。
归一化固定为：

```text
exposed = log(1 + count × exposure) / log(1 + maxCount × exposure)
value   = exposed ^ (1 / gamma)
```

无命中像素的 `ScalarField.Escaped=false` 且值为 0。它既能进入密度渐变，也能直接复用既有阈值、柔化、
反相与画布空间变换生成 Mask。

## 透明渐变与局部发光

密度着色不复用逃逸时间的“内部颜色”语义：零密度固定透明；非零密度在起止色之间插值，并让密度同时
缩放 Alpha。局部发光对预乘 Alpha RGBA 做可分离高斯卷积，再把原层 source-over 到光晕上，因此光晕
可以扩展到原透明区域。

局部发光只属于吸引子配方。作品级 Master Bloom 保持 G0008 原语义和旧指纹，两者不共享可编辑状态。

## 缓存与预算

- 点云键：节点版本、公式、A/B/C/D、预热、最终采样、Seed、当前采样预算；
- 密度键：点云摘要、尺寸、曝光、Gamma 和调度诊断；
- 着色键：密度摘要与渐变；
- 发光键：着色摘要与启用/Sigma/强度；
- 图层变换、混合与 Master Effects 不进入上述生成键。

单层最终采样上限 2M；一次求值所需吸引子合计上限 4M；需要密度计算的画布上限 16,777,216 像素。
所有长循环定期检查取消，缓存只在节点成功并再次通过取消检查后提交。
