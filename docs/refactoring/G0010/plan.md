# G0010：数学透镜计划

## 产品结论

在唯一的分形作品 Document 内增加只读观察模式，解释当前选中的分形层。首版覆盖 Julia、Mandelbrot、
递归树、L-System、Clifford 和 De Jong 吸引子，并分别以单点轨迹、层级路径和点云形成过程呈现。

## 首要约束

- SOLID 是实现评审第一顺位；分析、播放、Document 编排、坐标投影和 Avalonia 绘制职责分离；
- 公式递推、路径生成、Seed 派生和点云取景复用生产实现，不维护演示算法旁路；
- 只使用不可变结果、窄端口和三个朴素策略，不增加事件总线、通用节点框架或反射注册；
- 透镜是 Document Scope 会话态，不进入 v8 快照、Dirty、历史、创作图缓存键或导出；
- 不增加 Tool、Workbench Command、菜单和默认快捷键；
- 不使用 AIFLOW，不增加 Windows CI，不执行 Release、部署、ZIP、签名或发布门禁。

## 完成标准

- 三类数据形态和五种生成器均能生成有界、可取消的中文解释帧；
- Double/任意精度逃逸结果与生产像素一致，路径最终帧与生产几何一致，点云标注与密度取景一致；
- 支持点击、播放、暂停、单步、滑块、复位和取消；迟到结果不能覆盖新分析；
- 透镜操作不改变保存内容、预览指纹、Dirty 或撤销栈；
- Debug 构建、单元测试、格式门禁和 Standalone 烟雾通过。
