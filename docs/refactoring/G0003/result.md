# G0003 实施结果

> 实施日期：2026-09-03  
> 状态：纵向代码切片与自动化门禁完成；Standalone 视觉和真实 Host 导出待人工验收

## 已完成

- Julia 生成器、归一化标量场、独立逃逸掩码和线性渐变已实现；
- `RenderContext` 明确携带尺寸、质量、Seed 和 renderer v1；
- 草稿/精细预览与最终导出尺寸策略已经分离；
- 参数、画布、背景、Seed 和渐变可编辑并随作品保存；
- 自动预览具有 120 ms 合并窗口、协作取消和 generation 双重提交检查；
- PNG 导出通过 Host/Standalone 文件选择端口选择位置；
- 最终导出重新计算规范画布并采用临时文件原子替换，不依赖 UI 截图。
- 画布已经支持左键拖动平移和以鼠标指针为锚点的滚轮缩放；一次连续拖动只产生一次撤销记录；
- Julia 中心、尺度和常量改为高精度十进制文本，作品格式升级为 v2，并显式迁移 v1 双精度作品；
- 渲染上下文明确记录数值路径与精度；普通尺度走 `double`，深缩放自动进入 `BigInteger` 定点内核；
- 精度可在 32–1024 位配置，输入、指数、预览像素和画布均有资源预算，计算保持可取消。

## 自动化证据

- 相同 Julia 配方与上下文生成完全相同的标量值和逃逸掩码；
- 所有标量值均在 0..1，测试同时覆盖逃逸点和内部点；
- 渐变端点、Interior 色与 Alpha 映射正确；
- 生成器、渐变和导出观察取消；
- 模拟底层忽略取消并迟到时，最终指纹仍属于最新参数；
- PNG 签名、IHDR 尺寸和 IEND 正确；
- 原子写入取消时保留既有目标且不遗留临时文件；
- 草稿预览受 480/960 预算限制，最终输出保持规范尺寸。
- 高精度十进制在 `double` 无法区分 `1` 与 `1 + 1e-1000` 时仍保留差值；
- `1e-350` 尺度下的平移结果不会因 `double` 下溢归零；
- 自动精度选择、强制高精度、1024 位预览预算和任意精度 Julia 确定性均有测试；
- 居中与偏心两种滚轮缩放都验证了复平面锚点不漂移；
- v2 快照完整往返、v1 显式迁移、未知版本和恶意超大指数均有边界测试；
- 当前自动化套件共 30 项，全部通过。

## 已知边界

- 当前只有单一 Julia 生成器和两端点渐变；
- 尚未引入局部计算缓存，改变颜色仍会重新生成标量场；该优化属于后续内部创作图阶段；
- CPU 渲染适合首条切片，4K 高迭代作品的进度、分块和性能封板属于后续阶段；
- 1024 位精度的最终全尺寸导出可能耗时明显；当前优先保证确定性、资源有界与可取消，尚未引入分块缓存；
- 当前精度上限是产品资源边界，不代表无限精度或科研级误差证明；
- 人工检查应确认不同 DPI 下预览清晰、文件选择器可用、取消按钮反馈自然。
