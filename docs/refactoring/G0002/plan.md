# G0002 当下计划：作品领域模型与可持久化空闭环

## 目标

在复杂渲染之前建立“新建—修改—保存快照—Host 确认—关闭—恢复”的可信内容闭环。作品持久化的是版本化
配方，不是 ViewModel、Bitmap、文件路径或运行时任务。

## 工作项

1. 定义版本、画布、背景、Seed、Julia 参数、渐变和轻量呈现状态；
2. 建立集中资源预算和参数验证；
3. 实现严格、事务式 `DocumentContent` 编解码；
4. 实现 Revision/Dirty/AcceptChanges 语义；
5. 建立 Document Scope 内有界撤销/重做；
6. 恢复失败或取消时不发布半初始化状态；
7. 验证多实例隔离、往返一致、缺字段和未知版本。

## 验收标准

- 保存快照包含完整单一事实来源，恢复后值相等；
- 旧修订确认不能错误清除 Dirty；
- 未知内容 schema 和未知作品版本明确拒绝；
- 缺字段、非法颜色、非有限参数和超预算画布明确失败；
- 两个 Document 的作品、历史、修订和任务互不共享；
- Standalone 不冒充 Host 的文件信封和关闭确认实现。

## 明确不做

- 不把预览 Bitmap 或导出路径写入作品；
- 不兼容尚未存在的旧版本，不虚构迁移器；
- 不实现图层、效果链、变体收藏或 Workflow Artifact。
