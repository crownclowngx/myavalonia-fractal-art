# G0004 当下计划：变体探索与艺术化参数

## 目标

在不增加第二种分形公式和通用效果框架的前提下，把现有 Julia 数学参数页面推进为可连续探索的创作界面。
用户应能通过视觉预设、艺术滑杆、九宫格、锁定、收藏和续变完成第一轮“生成—挑选—再生成”闭环。

## 工作项

1. 定义艺术参数到 Julia 真实参数的稳定双向映射，禁止保存平行状态；
2. 用领域元数据声明可变参数的分组、范围、步长和分布；
3. 使用版本固定的伪随机算法，按作品 Seed、持久化轮次和候选序号生成 9 个可重现配方；
4. 支持 0.05–1.00 变异强度、只变形态、只变质感，以及 Seed/构图/形态/颜色锁定；
5. 支持采用、收藏、恢复、从候选或收藏续变；
6. 提供 3 个视觉预设和 3 个调色板；
7. 候选缩略图采用最多 3 路并发、64 项内存缓存、协作取消和整批提交；
8. 作品格式升级到 v3，保存探索轮次、设置、候选配方和收藏，并显式迁移 v1/v2；
9. 补齐领域、应用、Document、持久化与损坏输入测试。

## 完成标准

- 同一 v3 作品在同一轮生成字节语义一致的候选配方；
- 所有生成配方通过现有资源预算验证，不出现无界随机；
- 锁定分组在下一轮保持不变，只变形态/质感不越界修改其他分组；
- 任一候选能采用、撤销、收藏、恢复并作为下一轮基准；
- 取消或迟到批次不替换当前作品和上一批候选；
- 收藏和候选保存后仍能恢复真实配方，快照不包含 Bitmap；
- Debug/Release 构建、测试与格式门禁通过。

## 明确不做

- 不引入 G0005 的递归路径、第二种公式或公式选择器；
- 不提前建立 G0006 的节点图、效果链和持久化效果锁；
- 不实现磁盘缩略图缓存、GPU 渲染或跨插件 ImageLab 调用；
- 不使用 AIFLOW，不增加 Windows CI，不执行发布、部署或正式 ZIP 门禁。
