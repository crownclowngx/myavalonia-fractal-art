## 已交付

- 左侧创作入口按“时间逃逸 / L-System”分组。时间逃逸可选 Julia、Mandelbrot；L-System 下保留 G0005
  递归树兼容入口，不对旧作品做有损规则转换。
- 右侧改为上下文页签：时间逃逸只显示示例、创作、数学和外观；L-System 只显示示例、规则、绘制和外观；
  画布与变体作为两类生成器共用折叠区保留。
- Julia 提供 3 个既有可编辑起点；Mandelbrot 新增全景、海马谷、象谷 3 个起点；L-System 新增 Koch 雪花、
  Heighway 龙、Sierpiński 三角、经典分形植物、Hilbert 曲线 5 个起点。
- Mandelbrot 实现 `z₀=0、c=像素` 的 double 内核与任意精度定点参考内核，复用 `ScalarField`、渐变、预览和 PNG。
- L-System 实现统一验证、受预算逐轮展开、显式有界 Turtle 栈、方形逻辑画板归一化与 `PathGeometry` 输出，
  再复用 G0005 描边器进入 RGBA 图像面。

  诊断展示预计符号数和线段数。
- 变体始终保持当前公式；Mandelbrot 不产生无画面意义的 Seed 差异，L-System 不随机修改公理和产生式。
- 作品格式升级到 v5。v1–v3 继续迁移为 Julia；v4 Julia/递归树及候选按原语义迁移；v5 缺少新增定义时整体拒绝。

## 设计落点

SOLID 仍是第一顺位：Mandelbrot 公式、L-System 验证、展开、Turtle 解释、路径描边、示例目录、快照和 Document
编排由窄接口分离。两类生成器只在 `IArtworkGeneratorRenderer` 汇入同一应用管线，没有复制预览、导出、历史或文件事务。

实现没有引入反射公式扫描、多态 JSON、事件总线或通用 DSL。v5 采用追加式 `FractalGeneratorKind` 和普通不可变 record；
所有定义均由统一验证器检查，当前标签只选择渲染策略。L-System 规则集合实现内容相等，保证保存恢复不会因数组实例变化
被误判为 Dirty。

交互方案原建议把产生式做成表格并立即拆三个子呈现模型。最终首版采用多行规则文本和一个 Document Scope 呈现模型：
它仍只写回同一不可变作品，并由统一历史/验证/预览 generation 提交。该取舍减少了首版表格控件和消息层；如果 G0006
出现第三类编辑器，再按真实重复抽取子模型。

## 资源与兼容边界

- 公理 1–1,024 字符，产生式 1–32 条，单条替换不超过 4,096 字符；
- 迭代 0–12，同时受最多 250,000 个展开符号、50,000 条绘制线段约束；
- Turtle 栈最多 1,024 层，未知符号、括号失衡和退化路径均产生中文诊断；
- Mandelbrot 与 Julia 使用相同的 32–1,024 位精度政策和深缩放预览预算；
- v4 递归树继续调用原路径生成器，迁移不会将随机树伪装成确定性 L-System。
