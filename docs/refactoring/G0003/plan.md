# G0003 当下计划：第一条 Julia 纵向渲染切片

## 目标

建立最小但完整的 Julia 艺术生成链，贯通参数、显式上下文、取消、过期抑制、预览、保存恢复和 PNG 最终导出。

## 工作项

1. Julia 生成器输出归一化迭代标量场及独立逃逸掩码；
2. 线性渐变把标量场转换成框架无关的 RGBA 图像；
3. 显式 `RenderContext` 携带尺寸、质量、Seed 和渲染器版本；
4. 草稿预览使用受限尺寸，最终导出使用规范画布；
5. 参数变化取消旧任务，并在提交前再次检查 generation；
6. 实现 PNG 编码、保存位置选择和同目录原子替换；
7. 补齐确定性、取消、迟到、PNG 和原子写入测试。

## 验收标准

- 相同生成器版本、配方和上下文得到字节级一致结果；
- 标量值位于 0..1，未逃逸内部点具有独立语义；
- 连续改参后旧任务即使忽略取消并迟到，也不能覆盖最新预览；
- 预览和最终导出共享生成及渐变规则，但尺寸/质量策略明确不同；
- 导出直接计算完整画布，不截取 UI；
- 取消不会留下成功提示或半写目标文件。

## 明确不做

- 不在 G0003 引入 Mandelbrot、多节点图、缓存框架、Bloom 或多图层；
- 不让 Seed 伪随机改变 Julia 数学参数；Seed 作为显式作品上下文保存，供后续随机生成器使用；
- 不执行发布 ZIP 门禁。
