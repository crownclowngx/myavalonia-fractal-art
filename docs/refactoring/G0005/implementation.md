# G0005 实施方案

## 设计思路

第二种数据形态沿用现有应用外壳，只在真正变化的生成与渲染部分使用一个朴素的策略分派：

```text
ArtworkDefinition v4
    ├─ GeneratorKind = Julia
    │      → JuliaFieldGenerator → ScalarField → LinearGradientMapper
    └─ GeneratorKind = RecursiveTree
           → RecursiveTreePathGenerator → PathGeometry → PathStrokeRenderer
                                      ↓
                              RgbaImage → Preview / PNG
```

`ArtworkRenderPipeline` 负责验证作品并按 `FractalGeneratorKind` 选择唯一策略；策略自己组合本数据形态的窄端口。
Document、变体缩略图、导出器都只依赖原有 `IArtworkRenderPipeline`，因此没有出现第二套生命周期与保存逻辑。

## 路径语义

`PathGeometry` 使用 0–1 方形逻辑画板坐标，描边时按画布短边等比居中，避免宽高比扭曲分叉角度；它包含不可变快照形式的 `PathSegment` 集合。每条线段保存起点、终点和
`Level`，`MaximumLevel` 明确层级上限。路径对象不引用 Avalonia、Bitmap、画布像素或描边器：

- 预览和 PNG 在 `PathStrokeRenderer` 中才栅格化；
- 颜色由渐变起止色按层级插值；
- 线宽由基础线宽按层级衰减；
- 后续 SVG 导出可以直接消费 `PathGeometry`，无需从 PNG 反推路径；
- 未来替换描边实现不会改变递归树生成器。

## 确定性与预算

递归树从画布底部中心开始，使用显式栈展开。固定 SplitMix64 随机源只由作品 Seed 驱动，分叉按稳定顺序入栈，
所以相同输入会逐段重现。随机度只扰动当前分支角度，不改变深度和线段数量。

领域验证器同时约束：深度 1–12、每级分叉 2–3、角度 5–85°、长度衰减 0.45–0.85、随机度 0–1、
主干长度 0.05–0.6、基础线宽 0.5–40，以及总线段不超过 50,000。路径端口自身再次保护深度、分叉与
总线段预算，防止未来 SVG 用例绕过完整作品验证器后造成溢出或失控分配。

## 变体语义

候选配方升级为同时保存生成器类型、Julia 参数、递归树参数和渐变。当前生成器决定“形态”组实际修改哪套参数：

- Julia 修改复常量与迭代，且“全部”模式可修改复平面构图；
- 递归树修改深度、分叉、角度、长度衰减和随机度；
- 两者共用 Seed 与颜色变异；
- 候选不会随机切换生成器；
- 未激活生成器的参数不会被无意义修改，避免视觉等价候选产生不同缓存身份。

每个候选仍由统一 `ArtworkValidator` 验证，最多确定性重采样 8 次，失败时回退源配方。已有整批提交、
最多 3 路缩略图并发、64 项内存缓存、取消和迟到结果抑制不需要复制或重写。

## v4 持久化与迁移

v4 在作品和候选配方中增加 `generatorKind` 与 `recursiveTree`。编码前仍验证完整领域对象；解码到局部对象并
全部验证成功后才交给 Document。

- v1：先把双精度 Julia 转成高精度文本，再补入 Julia 类型和安全树默认值；
- v2：保留高精度 Julia，补空探索状态、Julia 类型和安全树默认值；
- v3：保留探索候选与收藏，并把作品和每个旧配方明确标记为 Julia；
- v4：要求生成器与树字段完整存在，未知枚举和非法预算由验证器拒绝。

这条迁移路线不依据字段外观猜测生成器，也不会把旧 Julia 作品误解释成递归树。

## SOLID 对照

| 原则 | G0005 落点 |
| --- | --- |
| 单一职责 | 树参数验证、路径生成、路径描边、策略选择、快照迁移和 Document 编排分离 |
| 开闭原则 | 新数据形态通过 `IArtworkGeneratorRenderer` 加入，预览、导出和 Document 无需增加算法分支 |
| 里氏替换 | Julia 与树策略遵守相同渲染、取消和 `RgbaImage` 返回契约 |
| 接口隔离 | 路径生成器只产生几何；描边器只消费几何；SVG 可绕过像素适配器 |
| 依赖倒置 | 应用管线依赖策略集合，树策略依赖路径与描边端口，组合入口提供具体实现 |

没有引入反射扫描、服务定位器、通用公式注册表或节点框架。当前两个稳定生成器使用枚举和唯一策略映射，
让错误配置能够在启动/首次解析时直接失败。
